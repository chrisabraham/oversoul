# people/

One canonical profile per person or company: clients, prospects, partners, vendors, and former clients. Everyone you work with has exactly one file here, whether or not they also have projects in `projects/`. Copy `templates/person.md` to start one; `docs/example-person.md` shows a filled-in one. Rules are in `AGENTS.md`. List every profile in `INDEX.md`.

This folder is empty in the template.
