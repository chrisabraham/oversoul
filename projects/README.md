# projects/

One short digest per project that already exists in your PM tool. A client with two PM projects gets two digests here and still has exactly one profile in `people/`. Every digest links to that profile and doesn't repeat it.

The full record stays in the PM tool; the digest is the part every agent needs. Copy `templates/project-digest.md` to start one. Rules are in `AGENTS.md`. List every digest in `INDEX.md`.

Don't use a PM tool? Delete this folder.

This folder is empty in the template.
