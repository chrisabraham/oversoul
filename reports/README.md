# reports/

One file per substantial agent session: a first pass, a review, a bulk change, an import. Name it `YYYY-MM-DD-agent-task.md` (for example `2026-01-05-claude-first-pass.md`) and start from `templates/report.md`.

Reports are how agents learn what other agents already did. Read the newest few before you start any large job, so you don't redo or undo someone else's work.

Reports are a log: write them once and don't edit them later. If a report turns out to be wrong, say so in a new one.

This folder is empty in the template.
